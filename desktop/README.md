# AtomFolio 메뉴바 앱

macOS 메뉴바에서 총 자산과 보유 종목 뉴스를 확인하는 작은 동반 앱입니다. 기존 AtomFolio
웹/서버 API(`/api/portfolio`, `/api/market/news`)를 그대로 재사용하며, 이 디렉터리는 별도의
Electron 프로젝트로 `src/`, `server/`의 웹 앱 코드는 건드리지 않습니다.

## 실행

```bash
cd desktop
npm install
npm start          # 프로덕션 API(https://atomfolio.vercel.app)를 바라봄
npm run dev         # 로컬 개발 서버(http://localhost:8787)를 바라봄 — 웹 쪽 npm run dev도 같이 띄워둘 것
```

메뉴바에 원자 모양 아이콘이 뜹니다. 처음 실행하면 연결 화면이 나오는데, 두 가지 방법으로
연결할 수 있습니다.

- **로그인 계정에 연결(권장)**: 웹 대시보드에 로그인한 상태에서 설정 → 계정 및 워크스페이스 →
  "데스크톱 연결 코드 생성"을 눌러 나오는 코드(`atomfolio_dt_...`)를 붙여넣습니다. 정식 OAuth는
  아직 없지만, 이 코드가 사실상 그 역할을 합니다 — 서버가 코드를 로그인 계정의 Bearer 토큰과
  동등하게 취급해(`server/deviceTokens.mjs`) 해당 계정의 워크스페이스로 자동 연결됩니다.
- **게스트 워크스페이스에 연결**: 로그인 없이 쓰던 기존 방식 그대로, 웹 대시보드(설정 →
  계정 및 워크스페이스)에 표시된 Workspace ID를 복사해 붙여넣으면 됩니다.

연결되면 보유 비중 상위 종목들이 중심(포트폴리오 총액)을 도는 원자 궤도로 표시됩니다.
드래그로 궤도를 돌리거나 가만히 두면 천천히 자동으로 도는데, 종목 하나를 클릭하면 그
종목의 평가금액·손익·비중이 아래 읽기 영역에 표시되고, 다시 클릭하거나 중심원을 클릭하면
전체 총액으로 돌아옵니다.

## 빌드 (로컬 확인용)

```bash
npm run build:mac
```

`release/` 아래에 서명되지 않은 앱 번들이 생성됩니다. 코드사이닝/노터라이즈는 이번
범위에 포함되지 않았습니다 — 로컬에서 실행 확인까지만 합니다.

## 알아둘 점

- **완전한 실시간이 아닙니다.** 뉴스는 60초 폴링 주기로 확인하므로, 실제 게재 시점과
  알림 사이에 최대 폴링 주기만큼(기본 60초) 지연이 있을 수 있습니다. 폴링 주기는
  `desktop/src/lib/store.mjs`의 `pollIntervalSec`로 조정 가능하지만, 공용 API에 과도한
  부하를 주지 않도록 60초 미만으로는 내려가지 않게 강제되어 있습니다.
- 앱이 포그라운드/팝오버가 닫혀 있어도 메인 프로세스에서 폴링과 알림은 계속 동작합니다.
- Workspace ID는 게스트 워크스페이스에 대한 접근 권한을 그대로 부여하는 값이라, 웹의
  설정 화면과 마찬가지로 평문으로 다룹니다.
- 데스크톱 연결 코드(`atomfolio_dt_...`)는 로그인 계정 전체에 대한 접근 권한을 부여하는
  값입니다 — Workspace ID보다 훨씬 강한 자격증명이니 스크린샷/로그 등으로 노출하지 않도록
  주의하세요. 새 코드를 생성하면 이전 코드는 자동으로 무효화되고, 웹 설정에서 "모든 데스크톱
  연결 해제"로 언제든 전부 끊을 수 있습니다.
