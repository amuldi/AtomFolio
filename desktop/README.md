# AtomFolio 메뉴바 앱

macOS 메뉴바에서 포트폴리오 평가금액·손익·비중을 바로 확인하고, 화면 위에 늘 떠 있는 작은
원자 위젯으로 보유 종목을 살펴보는 동반 앱입니다. 기존 AtomFolio 웹/서버 API
(`/api/portfolio`, `/api/market/news`)를 그대로 재사용하며, 이 디렉터리는 별도의 Electron
프로젝트로 `src/`, `server/`의 웹 앱 코드는 건드리지 않습니다.

## 실행

```bash
cd desktop
npm install
npm start          # 프로덕션 API(https://atomfolio.vercel.app)를 바라봄
npm run dev         # 로컬 개발 서버(http://localhost:8787)를 바라봄 — 웹 쪽 npm run dev도 같이 띄워둘 것
```

메뉴바에는 수익/손실을 색으로 나타내는 작은 점 아이콘이 뜹니다(빨강 = 수익, 파랑 = 손실,
회색 = 변동 없음) — 원자 모양은 아이콘이 아니라 화면에 별도로 떠 있는 원자 위젯 쪽입니다.
이 아이콘을 클릭하면 팝오버가 열립니다. 처음 실행하면 연결 화면이 나오는데, 두 가지 방법으로
연결할 수 있습니다.

- **로그인 계정에 연결(권장)**: 웹 대시보드에 로그인한 상태에서 설정 → 계정 →
  "데스크톱 연결 코드 생성"을 눌러 나오는 코드(`atomfolio_dt_...`)를 붙여넣습니다. 정식 OAuth는
  아직 없지만, 이 코드가 사실상 그 역할을 합니다 — 서버가 코드를 로그인 계정의 Bearer 토큰과
  동등하게 취급해(`server/deviceTokens.mjs`) 해당 계정의 워크스페이스로 자동 연결됩니다.
  **주의**: 설정 화면의 `WORKSPACE` 값(`user:...`)을 그대로 붙여넣으면 연결되지 않습니다 —
  그 값 자체는 인증 수단이 아니라서, 반드시 "데스크톱 연결 코드 생성" 버튼으로 만든
  `atomfolio_dt_...` 코드를 써야 합니다.
- **게스트 워크스페이스에 연결**: 로그인 없이 쓰던 기존 방식 그대로, 웹 대시보드(설정 →
  계정)에 표시된 Workspace ID를 복사해 붙여넣으면 됩니다.

## 팝오버 (메뉴바 아이콘 클릭)

가로로 넘기는 3페이지 구성이며, 열 때마다 항상 첫 페이지(요약)로 돌아갑니다.

1. **요약** — 총 평가금액, 오늘의 손익(금액·수익률), 활성 인사이트(손절/익절/배분 이탈 조건에
   걸린 게 있을 때만), 비중 상위 보유 종목 목록, 빠른 종목 추가(티커+수량). 포트폴리오가
   여러 개면 이 페이지 위에 늘 떠 있는 포트폴리오 선택 드롭다운으로 전환합니다. 뉴스/설정
   페이지는 페이저를 넘기거나(스와이프/페이저 점) 헤더의 ⚙ 버튼으로 이동합니다.
2. **뉴스** — 보유 종목 관련 최신 뉴스와 검색. 카드를 클릭하면 기본 브라우저로 열립니다.
3. **설정** — 기본(테마·원자 위젯 크기/불투명도·자동 실행) / 알림(인사이트·손절·익절·배분
   이탈 기준) / 고급(새로고침 주기·카테고리 필터·팝업 불투명도, 기본은 접혀 있음) 세 그룹.

## 원자 위젯

연결되면 화면 위에 늘 떠 있는 별도의 투명 창으로, 보유 비중 상위 종목들이 중심(포트폴리오
총액)을 도는 원자 궤도로 표시됩니다. 항상 왼쪽으로 천천히 자동 회전하고, 드래그로 직접
돌리면 놓는 순간의 방향·속도가 관성으로 이어지다가 서서히 다시 자동 회전으로 돌아옵니다.
종목 하나를 클릭하면 그 종목의 평가금액·손익·비중이 아래 읽기 영역에 표시되고, 다시
클릭하거나 중심원을 클릭하면 전체 총액으로 돌아옵니다.

- **크기 조절**: 창 가장자리를 직접 드래그하거나, 설정 → 기본의 슬라이더로.
- **불투명도**: 설정 → 기본에서 조절.
- **잠자기**: 메뉴바 아이콘 우클릭 메뉴 — 켜면 완전히 클릭 통과 상태가 되어 데스크톱 배경처럼
  가만히 떠 있기만 합니다.
- **드래그로 이동**: 빈 원자 배경(노드가 아닌 곳)을 드래그하면 창이 움직입니다 — 모디파이어
  키 없이 바로 됩니다. 진짜 macOS 네이티브 창 드래그라서, 화면 가장자리에서 잠깐 버티면
  macOS 자체의 Mission Control 기능으로 다른 Desktop(Space)으로 넘어갈 수도 있습니다(이
  부분은 실제 마우스 제스처가 필요해 자동 검증은 못 했습니다 — 직접 확인 필요). 손을 놓으면
  가장자리에 살짝 걸쳐 있던 경우 그 가장자리에 딱 맞춰 정렬됩니다.
- **우클릭 메뉴**: 요약/뉴스/설정 페이지로 바로 이동, 종목이 선택된 상태라면 "{종목} 뉴스
  보기"로 바뀌어 그 종목 뉴스로 바로 연결, 포트폴리오 전환(2개 이상 연결 시), 위젯 숨기기.
- 위젯을 숨겼다가 다시 켜면 현재 커서가 있는(=Dock이 떠 있는) 화면 가운데에서 다시 열립니다.

## 빌드 (로컬 확인용)

```bash
npm run build:mac
```

`release/` 아래에 서명되지 않은 앱 번들이 생성됩니다. 코드사이닝/노터라이즈는 이번
범위에 포함되지 않았습니다 — 로컬에서 실행 확인까지만 합니다.

## 알아둘 점

- **완전한 실시간은 아니지만, 포트폴리오 변경 사항은 몇 초 안에 반영됩니다.** 워크스페이스에
  뭔가 바뀌었는지만 확인하는 가벼운 체크를 5초마다 돌리다가(사용자가 조정할 수 없는 고정
  주기), 실제로 바뀐 걸 감지하면 그때 전체 데이터를 새로 받아옵니다. 뉴스·인사이트 재평가를
  포함한 전체 새로고침 자체는 여전히 더 긴 주기(기본 60초, 설정 → 고급의 "새로고침 주기"로
  조정 가능, 공용 API 보호를 위해 60초 미만으로는 내려가지 않음)로 따로 돕니다.
- 앱이 포그라운드/팝오버가 닫혀 있어도 메인 프로세스에서 폴링과 알림은 계속 동작합니다.
- Workspace ID는 게스트 워크스페이스에 대한 접근 권한을 그대로 부여하는 값이라, 웹의
  설정 화면과 마찬가지로 평문으로 다룹니다.
- 데스크톱 연결 코드(`atomfolio_dt_...`)는 로그인 계정 전체에 대한 접근 권한을 부여하는
  값입니다 — Workspace ID보다 훨씬 강한 자격증명이니 스크린샷/로그 등으로 노출하지 않도록
  주의하세요. 새 코드를 생성하면 이전 코드는 자동으로 무효화되고, 웹 설정에서 "모든 데스크톱
  연결 해제"로 언제든 전부 끊을 수 있습니다.
