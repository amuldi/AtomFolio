# 시연용 예시 포트폴리오

AtomFolio를 처음 보여줄 때 쓰는 예시 CSV 8개입니다. 실제 계좌가 아니라 시연용으로 만든 가상 데이터입니다.

- 모든 종목에 `종목코드`, `매수가`, `보유수량`, `통화`가 있어 "⚠ 수량 없음" 같은 경고 없이 표시됩니다.
- 2026-06-30부터 매월 말일과 2026-11-14의 기록이 있어, 요약 탭의 **이번 달 변화**(지난달 대비)와 월말 수익률 막대가 바로 채워집니다.
- 종목코드가 실제 티커라서 배포 사이트에서는 실시간 시세로 수익률이 다시 계산됩니다. 그래서 화면 수익률은 CSV에 적힌 값과 다를 수 있습니다.

| 파일 | 구성 | 보기 좋은 점 |
| --- | --- | --- |
| `미국 빅테크.csv` | Apple, Microsoft, NVIDIA, Alphabet, Amazon, Meta | 큰 수익 종목이 밝게 빛나는 모습 |
| `한국 대표주.csv` | 삼성전자, SK하이닉스, NAVER, 현대차, KB금융, LG에너지솔루션 | 원화 종목, 수익과 손실이 섞임 |
| `미국 배당주.csv` | SCHD, VYM, JEPI, Realty Income, Coca-Cola, P&G | 손익이 작아 차분한 원자 |
| `ISA 국내상장 ETF.csv` | TIGER 미국S&P500, TIGER 미국나스닥100, KODEX 200, TIGER 미국배당다우존스, ACE KRX금현물 | ETF 위주 계좌 |
| `연금저축 장기투자.csv` | KODEX 미국S&P500TR, TIGER 미국테크TOP10, KODEX 200TR, TIGER 리츠부동산인프라, KOSEF 국고채10년 | 주식·리츠·채권 분산 |
| `성장주 공격형.csv` | Tesla, Palantir, AMD, ARKK, Coinbase, Shopify | 손익 폭이 커서 빨강·파랑 빛이 모두 강함 |
| `글로벌 자산배분.csv` | VOO, VEA, VWO, BND, GLD, 삼성전자 | 원화·달러 혼합, 높은 분산 점수 |
| `손실 회복 대기.csv` | Intel, Nike, Pfizer, Boeing, 엔씨소프트, LG생활건강 | 손실 종목이 파랗게 빛나는 모습 |

## 형식

```csv
평가일,계좌,종목명,종목코드,매수가,보유수량,평가금액,수익률,통화
2026-11-14,해외주식,Apple,AAPL,195,18,4155.84,18.4%,USD
```

`평가금액`은 해당 통화 기준(달러 종목은 달러)입니다.
